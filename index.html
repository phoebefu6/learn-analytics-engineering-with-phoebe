Learn Analytics Engineering with Phoebe

The same warehouse, as a dbt project

A leader track on why analytics engineering became a role, what models-as-code actually changes, how a test suite works as a governance artifact, and what to buy versus build - with no code to write. And a builder track that rebuilds a marketplace warehouse you already know as a real dbt project: sources, staging, intermediate, dimensions, facts, a type-2 snapshot, four marts, 100 tests, model contracts and CI. The project in this repo runs: dbt build reports PASS=121, ERROR=0, and it reproduces the hand-built version's numbers to the cent. Every model on the site is the SQL dbt compiled, every test in the lab is the project's own, and the lineage graph is read from its manifest.

Each session ends with the questions to ask your data team.

The builder track 🛠️ · for practitioners · 10 sessions x 45 min (b10: 60) · real DuckDB in your browser

One project: Bazaar, the multi-merchant marketplace from learn-data-modeling, rebuilt as dbt. You already know the model, so every session is about the craft. Each page runs real DuckDB compiled to WebAssembly and executes the SQL dbt itself compiled - so what you query in the browser is what the project builds on a laptop.
